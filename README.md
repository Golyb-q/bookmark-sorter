# Bookmark Sorter

Локальная игра для разбора экспортированных браузерных закладок. Работает без backend и подходит для GitHub Pages.

## Что умеет

- импорт Netscape `bookmarks.html`;
- Tinder-подобный этап `удалить / оставить`;
- редактирование названия и URL;
- открытие текущей закладки в новой вкладке;
- свайпы, кнопки, клавиатура и Undo;
- сохранение прогресса в IndexedDB после каждого действия;
- экспорт обратно в Netscape Bookmark HTML;
- пустые папки не экспортируются;
- свои игры можно создавать, редактировать, импортировать и экспортировать как JSON.

## Типы игр

### `decision-tree`

Классическая игра: каждый вопрос имеет переход `Да` и `Нет`. Переход ведёт к следующему вопросу или сразу в папку.

Встроенная игра: **Structural Web Ontology**.

### `feature-space`

Старый режим пространства признаков с заранее заданными прототипами категорий. Каждый признак независим, а в конце профиль сравнивается с эталонами папок.

Режим оставлен для пользовательских игр и обратной совместимости.

### `cluster-space`

Новый кластерный режим. У него **вообще нет заранее заданных категорий или папок**.

Для каждой сохранённой закладки пользователь отвечает на одинаковый набор независимых вопросов. Ответы образуют профиль конкретной закладки в том виде, как пользователь ею пользуется:

- корень сайта может описывать весь сервис;
- конкретное видео — именно видео;
- статья — именно статью;
- отдельный инструмент внутри большого сайта — именно этот инструмент.

После прохождения всех закладок движок сравнивает реальные профили между собой и автоматически строит кластеры. Пользователь выбирает удобное количество групп и **даёт им названия только в конце**. Эти названия становятся папками итогового экспорта.

Встроенная игра: **Functional Web Space**.

Сейчас используются:

- deterministic `k-medoids`;
- `weighted Jaccard` по положительным признакам;
- ответ `Не знаю` не участвует в сравнении;
- совпадающие `Нет` почти не сближают две закладки только потому, что обе «не являются всем остальным интернетом».

## Дефолтные игры

Все встроенные игры находятся только в папке:

```text
games/
├── index.json
├── structural-web.json
└── functional-web-space.json
```

`index.html` не содержит встроенной копии конкретной игры.

`games/index.json` — манифест. Чтобы добавить ещё одну встроенную игру, достаточно положить JSON в `games/` и добавить его имя в манифест.

## Редактор игр

В разделе **Игры** можно создать:

- `+ Дерево решений`;
- `+ Прототипы`;
- `+ Кластеры`.

Для `decision-tree` редактируются папки, вопросы и переходы.

Для `feature-space` редактируются папки, независимые признаки и прототипы категорий.

Для `cluster-space` редактируются только независимые признаки и параметры кластеризации. Категории заранее не задаются принципиально.

Хороший вопрос для кластерного режима должен описывать наблюдаемое свойство **конкретной закладки**, а не требовать решить, какая функция сайта «главная». Несколько ответов `Да` одновременно — нормальное и ожидаемое состояние.

## Завершение кластерной партии

После последней закладки появляется лаборатория кластеров:

1. движок автоматически группирует похожие профили;
2. ползунком можно менять число групп;
3. для каждой группы показываются размер, характерные признаки и примеры закладок;
4. пользователь даёт группе название;
5. названия становятся папками `bookmarks.html`.

Неразобранные закладки по-прежнему попадают в `00 Входящие`.

## Сессии

Начатая партия хранит **снимок выбранной игры**. Если JSON встроенной игры обновился, уже идущая сортировка продолжает использовать старые правила. Для проверки новой версии надо начать новую партию.

В кластерном режиме в IndexedDB дополнительно сохраняются ответы на признаки и состояние найденных кластеров. Эти технические данные не записываются в Netscape Bookmark HTML.

## GitHub Pages

1. Распакуй содержимое архива в корень репозитория.
2. Убедись, что рядом с `index.html` есть папка `games/`.
3. В GitHub открой **Settings → Pages**.
4. Выбери публикацию из нужной ветки (`main`) и `/ (root)`.
5. Открой выданный GitHub Pages URL.

Сборка, npm и backend не нужны.

> При открытии `index.html` через `file://` браузер может запретить загрузку JSON через `fetch`. Для GitHub Pages это не проблема. Локально используй любой простой HTTP-сервер, например `python -m http.server`.

## Приватность

Файл закладок обрабатывается в браузере. Серверная база и загрузка пользовательских bookmarks на backend отсутствуют.
