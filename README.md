# Bookmark Sorter

Статический local-first сортировщик браузерных закладок. Импортирует Netscape/Chrome/Firefox/Yandex `bookmarks.html`, превращает разбор в свайп-игру и экспортирует новое дерево папок.

## Что умеет

- импорт HTML-экспорта закладок;
- этап «оставить / удалить»;
- редактирование названия и URL;
- yes/no-классификатор по онтологии:
  - `10 Среды`
  - `20 Пространства`
  - `30 Объекты`
  - `40 Представления`
  - `50 Операторы`
- `? Не уверен` → `00 Входящие`;
- ручной выбор конечной категории;
- свайпы, кнопки и стрелки клавиатуры;
- Undo (`Ctrl/Cmd+Z`);
- автосохранение всей сессии в IndexedDB после каждого действия;
- экспорт в обычный Netscape Bookmark HTML;
- пустые папки автоматически не экспортируются;
- неразобранные закладки при промежуточном экспорте попадают в `00 Входящие`;
- приложение не отправляет закладки на сервер.

## GitHub Pages

Самый простой вариант:

1. Создай новый репозиторий.
2. Положи `index.html` в корень репозитория.
3. Commit + push.
4. GitHub → **Settings → Pages**.
5. Source: **Deploy from a branch**.
6. Branch: `main`, folder: `/ (root)`.
7. Save.

Сборка не нужна: приложение — один статический HTML-файл.

## Локальный запуск

Можно просто открыть `index.html`, но для поведения, максимально похожего на GitHub Pages, лучше:

```bash
python -m http.server 8080
```

и открыть `http://localhost:8080`.

## Принцип классификации

Классифицируется не домен и не тематика, а то, **что обозначает конкретная закладка**.

Пример:

- `youtube.com` → Среда;
- канал → Пространство;
- конкретное видео → Объект;
- результаты поиска → Представление;
- Catbox → Оператор.

Темы вроде `Linux`, `AI`, `anime`, `torrent` намеренно не являются частью дерева.
## Управление

- Свайп влево/вправо или стрелки клавиатуры — ответ «нет/да».
- Кнопки под карточкой выполняют те же действия и не конфликтуют со свайпами.
- Нажмите на заголовок карточки или кнопку `↗ Открыть`, чтобы проверить обычную `http/https`-закладку в новой вкладке перед решением.
- `javascript:`/`data:` и другие специальные URL намеренно не открываются из интерфейса.
- Ручной выбор категории доступен на этапе классификации.
