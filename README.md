# Bookmark Sorter

Локальная игра для разбора экспортированных браузерных закладок. Работает без backend и подходит для GitHub Pages.

## Что умеет

- импорт Netscape `bookmarks.html`;
- Tinder-подобный этап `удалить / оставить`;
- редактирование названия и URL;
- открытие текущей закладки в новой вкладке;
- свайпы, кнопки, клавиатура и Undo;
- сохранение прогресса в IndexedDB после каждого действия;
- ручной выбор любой папки результата;
- экспорт обратно в Netscape Bookmark HTML;
- пустые папки не экспортируются;
- свои игры можно создавать, редактировать, импортировать и экспортировать как JSON.

## Два типа игр

### `decision-tree`

Классическая игра: каждый вопрос имеет переход `Да` и `Нет`. Переход ведёт к следующему вопросу или сразу в папку.

Встроенная игра: **Structural Web Ontology**.

### `feature-space`

Новая игра: вопросы независимы друг от друга и образуют вектор признаков сайта. В конце движок сравнивает ответы с прототипами категорий и показывает несколько ближайших категорий с процентами похожести.

Это позволяет сайту одновременно быть похожим, например, и на соцсеть, и на медиабиблиотеку — ранняя развилка не уничтожает другие признаки.

Встроенная игра: **Functional Web Space**.

Прототип категории хранит для каждого важного признака одно из трёх состояний:

- `1` — ожидается `Да`;
- `0` — ожидается `Нет`;
- отсутствие признака — неважно.

Положительные совпадения дают основной score, а нарушение явно заданных отрицательных признаков снижает его.

## Дефолтные игры

Все встроенные игры находятся только в папке:

```text
games/
├── index.json
├── structural-web.json
└── functional-web-space.json
```

`index.html` не содержит встроенной копии конкретной игры.

`games/index.json` — манифест:

```json
{
  "games": [
    "structural-web.json",
    "functional-web-space.json"
  ]
}
```

Чтобы добавить ещё одну встроенную игру, достаточно положить JSON в `games/` и добавить его имя в манифест. Движок менять не требуется.

## Редактор игр

В разделе **Игры** можно создать:

- `+ Дерево решений`;
- `+ Пространство признаков`.

У обоих типов общий редактор дерева папок.

Для дерева решений редактор позволяет создавать вопросы и связывать ответы с вопросами/папками.

Для пространства признаков редактор позволяет:

- создавать признаки-вопросы;
- задавать вес каждого признака;
- выбирать папку-категорию;
- включать/выключать её как прототип;
- для каждого признака задавать `должно быть Да / должно быть Нет / неважно`;
- запускать тестовый прогон без импорта закладок.

## Сессии

Начатая партия хранит **снимок выбранной игры**. Если JSON встроенной игры обновился, уже идущая сортировка продолжает использовать старые правила. Для проверки новой версии надо начать новую партию.

Для `feature-space` у классифицированной закладки внутри локальной сессии сохраняются ответы на признаки и ближайшие scores. В обычный bookmarks HTML эти технические данные не экспортируются.

## GitHub Pages

1. Распакуй содержимое архива в корень репозитория.
2. Убедись, что рядом с `index.html` есть папка `games/`.
3. В GitHub открой **Settings → Pages**.
4. Выбери публикацию из нужной ветки (`main`) и `/ (root)`.
5. Открой выданный GitHub Pages URL.

Сборка, npm и backend не нужны.

> При открытии `index.html` через `file://` браузер может запретить загрузку JSON через `fetch`. Для GitHub Pages это не проблема. Локально используй любой простой HTTP-сервер, например `python -m http.server`.

## Приватность

Файл закладок обрабатывается в браузере. Серверная база и загрузка пользовательских bookmarks на backend отсутствуют.
