# Bookmark Sorter v2.1

Статическое local-first приложение для разбора и классификации экспортов браузерных закладок. Работает на GitHub Pages без backend, npm и сборки.

## Файлы проекта

```text
index.html
structural-web.json
README.md
```

`index.html` — движок игры. Он больше **не содержит копию Structural Web Ontology**.

`structural-web.json` — default preset. При запуске движок загружает именно `./structural-web.json`, поэтому дальнейшие изменения нашей классификации требуют правки только этого файла.

## Что умеет

- Импорт Netscape/Chrome/Firefox/Yandex `bookmarks.html`.
- Tinder-подобный отбор: удалить / оставить.
- Редактирование названия и URL перед классификацией.
- Свайпы, кнопки и клавиатура.
- Открытие закладки в новой вкладке перед решением.
- Ручной выбор любой папки текущей игры.
- Прогресс и Undo.
- Сохранение текущей партии в IndexedDB после действий.
- Экспорт обратно в Netscape Bookmark HTML.
- Пустые категории не создаются в экспорте.
- Неразобранные ссылки попадают во входящие выбранной игры.

## Игры-классификаторы

Движок не знает о конкретной онтологии. Preset задаёт:

- дерево папок результата;
- дерево yes/no-вопросов;
- переходы `Да` и `Нет` либо к другому вопросу, либо в папку;
- корневой вопрос;
- название папки входящих.

Default preset **Structural Web Ontology** — наша схема `Среды / Пространства / Объекты / Представления / Операторы`.

Пользователь может клонировать default preset, создавать свои игры, редактировать дерево папок и вопросов, валидировать граф, тестировать его на пробной закладке и импортировать/экспортировать presets в JSON.

Начатая партия хранит **снимок preset'а**, поэтому обновление `structural-web.json` не меняет правила уже идущей сортировки. Чтобы проверить новую версию онтологии, начни новую партию.

## Structural Web Ontology 1.2

В этой версии после реального тестирования закладок:

- удалена слишком широкая категория `Миры`;
- добавлены `Среды / Диалоговые` для ChatGPT, Character.AI и похожих систем;
- добавлены `Среды / Игровые` для постоянных игровых систем вроде TETR.IO;
- одиночные игры/демо могут уйти в `Операторы / Испытать`;
- `Сети ↔ Библиотеки` теперь различаются по ядру системы: отношения пользователей или самостоятельный корпус материалов;
- `Преобразовать` проверяется раньше `Вычислить`;
- вопросы `Преобразовать ↔ Вычислить` переписаны так, чтобы AES, Caesar cipher, Tupper и обычные калькуляторы различались естественнее.

## GitHub Pages

1. Положи `index.html`, `structural-web.json` и `README.md` в корень репозитория.
2. Открой `Settings → Pages`.
3. Source: `Deploy from a branch`.
4. Выбери `main` и `/ (root)`.

На GitHub Pages `index.html` загрузит:

```text
./structural-web.json
```

Если `structural-web.json` отсутствует, повреждён или содержит невалидный граф, движок покажет ошибку и не даст начать новую партию с default preset. Встроенного fallback больше нет намеренно.

Из-за `fetch()` простой запуск `index.html` через `file://` больше не является поддерживаемым способом тестирования default preset. Для локального запуска используй любой статический HTTP-сервер, например:

```bash
python -m http.server 8000
```

и открой `http://localhost:8000/`.

## Хранение данных

- Текущая партия: IndexedDB (`bookmark-sorter-v2`).
- Пользовательские игры: `localStorage`.
- Никакие закладки не отправляются на сервер.

## Формат preset JSON

Минимальный пример:

```json
{
  "id": "my-game",
  "name": "Моя игра",
  "version": "1.0.0",
  "inboxLabel": "00 Входящие",
  "rootQuestionId": "q1",
  "folders": [
    {"id":"a","name":"Категория A","children":[]},
    {"id":"b","name":"Категория B","children":[]}
  ],
  "questions": {
    "q1": {
      "id": "q1",
      "text": "Это относится к A?",
      "yes": "f:a",
      "no": "f:b"
    }
  }
}
```

Переходы:

- `q:<id>` — перейти к вопросу;
- `f:<id>` — завершить классификацию в папке.

## Безопасность

`javascript:` и `data:` закладки сохраняются при экспорте, но приложение не открывает и не исполняет их из карточки.
